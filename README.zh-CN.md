# zjooc-helper 简体中文说明

zjooc-helper 是一个用于 zjooc 学习页面的 Tampermonkey/油猴脚本。它主要用于改善学习页面的视频播放稳定性，减少因为播放器卡顿、清晰度线路异常、页面状态不同步带来的手动处理。

## 主要优点

- 页面右侧添加 `开始学习` 和 `停止学习` 按钮。
- 视频自动静音，并保持 `1 倍速` 播放。
- 支持跳过已完成内容。
- 支持文档类学习内容的自动完成按钮点击。
- 检测视频时间是否长时间不动，判断播放是否卡住。
- 卡住时优先在 `高清 / 标清 / 超清` 三个清晰度之间循环切换。
- 如果多次切换清晰度仍然无法恢复，自动刷新整个网页。
- 刷新后会自动继续学习，不需要再次手动点击 `开始学习`。
- 所有等待时间、卡顿阈值、刷新策略都可以在脚本顶部 `config` 中调整。

## 适用场景

- 网络波动导致视频进度卡住。
- 从一个视频切换到另一个视频后播放器不加载。
- 清晰度线路异常，需要切换清晰度触发重新拉流。
- 页面刷新后希望自动继续当前学习流程。

## 使用前提醒

请遵守你所在学校、课程和 zjooc 平台的相关规则。本脚本用于个人学习辅助、播放稳定性改善和浏览器脚本学习，不建议用于任何违反课程要求或平台规则的用途。
