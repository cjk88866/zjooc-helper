# zjooc-helper 繁體中文說明

zjooc-helper 是一個用於 zjooc 學習頁面的 Tampermonkey/油猴腳本。它主要用來改善學習頁面的影片播放穩定性，減少因播放器卡頓、畫質線路異常、頁面狀態不同步而需要手動處理的情況。

## 主要優點

- 在頁面右側加入 `開始學習` 和 `停止學習` 按鈕。
- 影片自動靜音，並保持 `1 倍速` 播放。
- 支援跳過已完成內容。
- 支援文件類學習內容的自動完成按鈕點擊。
- 偵測影片時間是否長時間不動，判斷播放是否卡住。
- 卡住時優先在 `高清 / 標清 / 超清` 三個畫質之間循環切換。
- 如果多次切換畫質仍然無法恢復，會自動重新整理整個網頁。
- 重新整理後會自動繼續學習，不需要再次手動點擊 `開始學習`。
- 所有等待時間、卡頓門檻、重新整理策略都可以在腳本頂部 `config` 中調整。

## 適用場景

- 網路波動導致影片進度卡住。
- 從一個影片切換到另一個影片後播放器不載入。
- 畫質線路異常，需要切換畫質觸發重新拉流。
- 頁面重新整理後希望自動繼續目前學習流程。

## 使用前提醒

請遵守你所在學校、課程和 zjooc 平台的相關規則。本腳本用於個人學習輔助、播放穩定性改善和瀏覽器腳本學習，不建議用於任何違反課程要求或平台規則的用途。
