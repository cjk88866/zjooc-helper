# Changelog

## 1.1.0

- Keep video playback at 1x speed and muted.
- Add stall detection when the video time stops moving.
- Rotate quality among `高清 / 标清 / 超清` when playback is stuck.
- Add fallback page reload if repeated quality switching cannot recover playback.
- Add auto-resume after recovery reload.
- Add configurable `stuck`, `qualityCooldown`, `maxQualityAttempts`, and `reloadDelay`.
- Add trilingual documentation: Simplified Chinese, Traditional Chinese, and English.
- Add sponsor QR images.

## 1.0.1

- Original userscript behavior from upstream: video/document learning automation, navigation to the next item, and skip completed content.
